# Avalik Conector · atualizações

Instaladores do **Avalik Conector**, app Windows da ARTTICO para os restaurantes clientes.

- Baixar a versão mais recente: [Releases](https://github.com/lucasgrupoarttico-bit/avalik-atualizacoes/releases/latest)
- O app instalado procura versão nova aqui sozinho e instala ao reiniciar.
- Funciona só com o código de pareamento gerado pela ARTTICO.

O código-fonte fica em repositório privado. Este repositório guarda só as versões publicadas.
